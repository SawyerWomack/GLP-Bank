CONTRIBUTING

Adding a new GLP

This site is a static page, so new GLPs get added by editing two things in the project and pushing to GitHub:

1. Drop the write-up as a PDF into the glp-files/ folder.

2. Add one entry to glp-data.js with the title, time, group size, a short summary, and the filename you just added.

Commit and push — GitHub Pages picks it up automatically within a minute or two.
